## Method

- Repository stats, traffic, contributors, forks, issues, pull requests: the
  GitHub REST API.
- Star growth: the REST stargazer list with the
  `application/vnd.github.star+json` media type, which returns each
  `starred_at` for this token; the endpoint is admin-only for others.
- Search data: the Search Console API, read with the service account the
  `cloud-gsc-suganthan-kittray` MCP is configured with. The window is the 28
  days ending 2026-11-20 — the last date the API carries. Every reading uses
  `dataState=all`; the re-read was taken through the same service account by
  `.claude/ops/monitor-gsc-traffic.ps1`.
- Sitemap file contents: the two XML files fetched directly.

No causal claim is made: GitHub's traffic data cannot attribute a star to a
referrer, and the referral links the launch wave will carry are not yet in the
window.
