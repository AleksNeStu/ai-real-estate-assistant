## Method

- Repository stats, traffic: the GitHub REST API.
- Star growth: the REST stargazer list with the
  `application/vnd.github.star+json` media type, which returns each
  `starred_at` for this token; the endpoint is admin-only for others.
- Search data: the Search Console API, read with the service account the
  `cloud-gsc-suganthan-kittray` MCP is configured with.

No causal claim is made: GitHub's traffic data cannot attribute a star to a
referrer, and the referral links the launch wave will carry are not yet in the
window.
