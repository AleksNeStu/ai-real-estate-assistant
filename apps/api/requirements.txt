# Backend runtime dependencies - PINNED.
#
# Every entry is an exact version. The floors this file used to carry let the
# installer resolve the newest match at install time, so the CI runner, the
# container image and the local venv each ended up with a different set. A
# newer sqlalchemy (2.0.51 -> 2.1.8) changed what mypy reports, and the type
# check CI now gates on failed on code that was correct locally. An exact
# version makes the three environments agree by construction.
#
# This file is the single runtime manifest: the container image installs it
# and nothing else, and CI installs it plus the project itself with
# `--no-deps`, so no floor declared in pyproject.toml can pull a different
# version in behind the pin.
#
# To change a version: edit the pin here, then prove it still resolves
#   cd apps/api && python -m pip install --dry-run -r requirements.txt
# (`make check-deps`), reinstall the local venv from this file, and run the
# local gate (scripts/ci/ci_parity.py) before trusting a local result.
#
# The comments below keep the security rationale each floor carried - the
# pins are the floor now, not a range.
#
# The tooling the CI gates run with (pytest, ruff, mypy) lives in
# requirements-dev.txt, so it stays out of the container image.
