# Test and type-check tooling - PINNED.
#
# The runtime manifest is requirements.txt; this file is the tooling the CI
# gates and the local CI-parity gate run with: the test runner and its
# plugins, the linter and the type checker. It is a separate file on purpose:
# requirements.txt ships into the container image, and the image does not
# need a type checker.
#
# Every entry is an exact version for the same reason as in requirements.txt:
# a floating tool version changes the verdict of a gate without a code
# change. mypy 1.x and 2.x report different sets of errors on the same
# source, and a new pytest can fail a suite that passed the day before.
#
# To change a version: edit the pin here, reinstall, and run the local gate
# (scripts/ci/ci_parity.py) before trusting a local result.
#
#   cd apps/api && uv pip install -r requirements-dev.txt
